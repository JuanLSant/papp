# ar-fifa-experience

Aplicación interactiva e informativa usando realidad aumentantada con tematica de la fifa , tiene su version en electron  

## Tecnologías Utilizadas
* HTML
* JavaScript / TypeScript
* CSS Modules 


## Características Principales
* Uso de modelos 3d y realidad aumentada
* Lector de qr para desbloquear tarjetas
* Uso de la api de google maps
* quiz interactivo
* uso de filtros a imagenes y videos
* Interfaz responsiva y modular.
